# Hashpass Regular Tutor

Представляет собой небольшой, но очень полезный скрипт для тренировки в регулярных выражениях. 

Подойдет как для начинающих специалистов, так и для тех, кто считает, что знает регулярные выражения, но хочет потренироваться.

Проходи честно, воин!

## Запуск
```
wget https://raw.githubusercontent.com/Bunnyton/regular_tutor/refs/heads/main/tutor.sh
```
```
chmod +x ./tutor.sh
```
```
./tutor.sh
```
